# Validate ESA CCI Biomass year and version arguments

Validate ESA CCI Biomass year and version arguments

## Usage

``` r
validate_esacci_biomass_args(esacci_biomass_year, esacci_biomass_version)
```

## Arguments

- esacci_biomass_year:

  Numeric or character, year to validate

- esacci_biomass_version:

  Character, version to validate

## Value

List with validated esacci_biomass_year and esacci_biomass_version
