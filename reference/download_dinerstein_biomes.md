# Download RESOLVE Ecoregions shapefile

Downloads the global RESOLVE Ecoregions 2017 shapefile from the official
source.

## Usage

``` r
download_dinerstein_biomes(output_folder = "data/ECOREGIONS", timeout = 600)
```

## Arguments

- output_folder:

  Character, directory to save and extract files (default:
  "data/ECOREGIONS")

- timeout:

  Numeric, download timeout in seconds (default: 600)

## Value

Character, path to the extracted shapefile
