# List tiles that intersect with a region of interest

List tiles that intersect with a region of interest

## Usage

``` r
list_tiles_for_roi(roi, tiles_dir, pattern)
```

## Arguments

- roi:

  sf object or bbox representing region of interest

- tiles_dir:

  Character, directory containing tile files

- pattern:

  Character, regex pattern to match tile files

## Value

Character vector of file paths
